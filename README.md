# LDG_climate_state

Latitudinal Diversity Gradient (LDG) analysis workflow for deep-time marine biodiversity and climate-state reconstruction.

This repository provides the R code and associated data used to reconstruct Phanerozoic marine latitudinal diversity gradients, estimate LDG slopes, compare their strength among climate states, evaluate hemispheric differences, and assess the robustness of the results to sampling and spatial structure.

## Overview

The main goals of this project are to:

1. reconstruct sampling-standardised marine invertebrate richness across palaeolatitude;
2. estimate LDG slopes through geological time;
3. compare LDG strength among coldhouse, coolhouse, transitional, warmhouse, and hothouse climate states;
4. analyse Northern and Southern Hemisphere LDGs separately as well as in the combined dataset;
5. evaluate the robustness of LDG estimates to sampling completeness, spatial coverage, grid resolution, latitude-bin configuration, and slope-calculation method;
6. test whether hemisphere-specific LDG differences are associated with sampling structure.

The principal analysis uses equal-area spatial cells and balanced resampling within palaeolatitudinal bands before fitting hemisphere-specific LDG slopes. The main settings are a **250-km spatial grid**, a **sampling coverage threshold of 0.7**, and **12 equal-area latitude bins**, with alternative settings used for sensitivity analyses.

## Data update

The Paleobiology Database (PBDB) occurrence dataset used for the current manuscript revision was **re-downloaded on 3 August 2026**.

This dataset supersedes the PBDB snapshot used in earlier versions of this repository and ensures that all revised analyses are based on the updated fossil occurrence records available at that date.

The refreshed PBDB dataset used by the current workflow is stored as:

`data/raw/pbdb_data_2.RDS`

When PBDB downloading is disabled, `R/00_data_preparation.R` reads this archived dataset directly. Retaining this snapshot in the repository ensures that the analyses associated with this version can be reproduced independently of subsequent changes to the live PBDB database.

Other core datasets include:

* climate-state classifications used in the analysis, based on Judd et al. (2024);
* geological time-bin information used for stage-level analyses and visualisation;
* palaeogeographic reconstruction data, including the SC16 reconstruction used in the principal workflow;
* processed occurrence and richness datasets generated by the analysis pipeline.

## Main analysis scripts

The principal scripts are located in `R/`:

* `000_main_new.R` — master controller for the current analysis workflow
* `00_data_preparation.R` — PBDB data import, cleaning, temporal binning, and palaeogeographic preparation
* `00_data_distribution_map_Fig.S1.R` — fossil-data distribution and sampling figure
* `01_LDG_calculation.R` — equal-area richness calculation and sampling standardisation
* `02_LDG_slope_per_cell.R` — per-cell LDG slope estimation
* `02_LDG_slope_per_cell_sensitivity_test.R` — sensitivity analyses for LDG slope estimation
* `02_LDG_slope_fig_per_cell.R` — principal LDG slope figure
* `02_LDG_slope_fig_per_cell_FigS4.R` — supplementary slope figure
* `02_LDG_percentile_eras_FigS5.R` — LDG percentile curves separated by geological era
* `02_LDG_slope_fig3_per_cell_FigS6S7.R` — Northern and Southern Hemisphere supplementary LDG figures
* `02b_LDG_slope_QC_sensitivity.R` — quality-control and robustness analyses
* `02_03_LDG_slope_per_cell_allcells_climate_state.R` — alternative slope-estimation and robustness analyses
* `03_LDG_compared_in_climate_state_per_cell.R` — comparison of LDG slopes among climate states
* `03b_LDG_wilcoxon_by_hemisphere_climate_state.R` — pairwise Wilcoxon tests for Northern and Southern Hemispheres
* `04_LDG_completeness_estimate_FigS2.R` — completeness analyses
* `05_high_latitude_coverage_summary_FigS3.R` — high-latitude coverage assessment
* `06_NH_SH_slope_bivariate_sampling_FigS8.R` — relationship between hemispheric LDG differences and sampling structure
* `options.R` — global analysis parameters

Core helper functions are stored in `R/functions/`, including:

* `calculate_Info.R`

## Main analysis settings

The principal analysis uses:

* spatial grid spacing: **250 km**
* sampling coverage threshold: **0.7**
* equal-area latitude bins: **12**
* stage-level temporal resolution
* separate Northern and Southern Hemisphere slope estimation
* balanced resampling for the principal per-cell LDG slope estimates

Alternative grid sizes, latitude-bin configurations, sampling thresholds, and slope-estimation approaches are used in sensitivity analyses where applicable.

## Requirements

The workflow is implemented in R. Major packages used across the analyses include:

`tidyverse`, `data.table`, `ggplot2`, `dplyr`, `iNEXT`, `dggridR`, `sf`, `terra`, `palaeoverse`, `deeptime`, `patchwork`, and `cowplot`.

Package requirements vary among individual scripts.

## Running the workflow

Clone the repository and run the analyses from the repository root directory.

The current master controller is:

```r
source("./R/000_main_new.R")
```

`000_main_new.R` defines the latitude-bin settings and the scripts to be run. Individual analysis and figure scripts can also be sourced separately when reproducing a particular component of the study.

Because several stages of the workflow generate intermediate outputs that are subsequently read by later scripts, the working directory should remain set to the repository root.
